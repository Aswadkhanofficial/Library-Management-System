# Library-Management-System

A Java Swing GUI application for a Library Management System, focusing on custom exception handling and input validation.

## Files Included

- `src/LibraryManagementSystem.java`
- `src/EmptyFieldException.java`
- `src/InvalidRollNumberException.java`
- `src/InvalidDateException.java`
- `src/NullSelectionException.java`

## Key Features

- **Graphical User Interface (GUI):** Built using Java Swing.
- **UI Components:** Utilizes labels, text fields, combo boxes, radio buttons, and a text area.
- **Error Handling:** Implementation of `try-catch`, `throw`, and `finally` blocks.
- **Custom Exceptions:** Custom-defined exception classes for strict input validation.
- **User Feedback:** Displays success and error messages using `JOptionPane`.

## How to Run

Navigate to the `src` directory, then compile and execute the program using the following commands:

```bash
cd src
javac *.java
java LibraryManagementSystem
